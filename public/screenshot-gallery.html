Bot Configuration

Everything that governs how the bot behaves on a position, set per position and saved field by field: when a rebalance triggers and how far a position may fall before the Impermanent Loss Guard stops it, how often a rebalance is allowed, the range and slippage it works within, and the contracts and RPC it talks to. Every row carries a circle-i explaining what the setting does and how to tune it.

Range is headed by a “No Override” toggle with two modes. Turned off, the badge reads “Use Settings Below” and Price Range Extension, Full-Range and Position Offset are live — the next rebalance applies them. Turned on, the badge reads “Re-Use Existing Position Range”, those three fields grey out, and the next rebalance keeps the position’s existing range re-centred on the current price. On is the default for a position that has never been configured. The toggle never clears the fields it disables, so flipping back restores your settings intact.

Action Dialogs

Dialogs you act in, rather than merely read: each one either changes app state through a form control, or asks you to work a dynamic list and decide from it. They share a common shape — title top-left, a “Close” button at the top right, and any primary action at the bottom.

Info Dialogs

Responsive Design

LP Ranger's dashboard adapts to smaller viewports, collapsing to a single-panel-per-row layout below 1981px so each card remains readable on laptops, tablets, and phones.
